# Plan: `--export-grid` mode in pixel-assert + CI asset PR automation

## Goal

Slice verified glyph cell crops out of real terminal captures (macOS Terminal.app, Windows conhost/wt, Linux xterm) and composite them into unlabeled PNG previews delivered via an automated `chore(assets)` pull request. Markdown stays static; only binaries in `assets/` drift.

## Locked decisions

- Implemented **inside `crates/pixel-assert`** (new `src/grid.rs`). No font/text deps; deps stay exactly: `image`, `serde`, `serde_json`, `clap`, `anyhow`, `icon-catalog`.
- Filter **strictly** to the 3-way AND-gate intersection of `overall == "pass"` ids across linux/macos/windows `verdicts.json`. Fail closed on `structural_fail`, `pass1_support == false`, or candidate-universe mismatch.
- Outputs written to `--export-grid <dir>`:
  - `universal-grid.png` — survivor tiles, fixed **16 columns**, 1 px `#000000` padding border per tile, ordered by `(Block::ALL order, codepoint)`, blank separator row between Unicode blocks.
  - `universal-matrix.png` — per-survivor row of `[macOS | Windows | Linux]` crops.
  - `grid-index.json` — deterministic position→icon metadata map.
- Crops are the **clean 1×1 icon cell** (`cal.cell_box(3, band)` — col 0-indexed 3), never sentinel/control columns, **never scaled**. Platforms have differing cell sizes → uniform slot = max crop dims across platforms, crop centered on black, no resampling.
- Delivery = **automated PR** (`peter-evans/create-pull-request`): branch `chore/update-assets` → `main`, commit/title `chore(assets): update platform grid previews`, `add-paths: assets/*`. Workflow-root `permissions: contents: read`; elevated `contents: write` + `pull-requests: write` **only on the `manifest` job**. PR step guarded to `github.ref == 'refs/heads/main'`.
- New static `README.md` (+ minimal `GALLERY.md`) embedding `assets/universal-matrix.png` / `assets/universal-grid.png` via relative paths.

## Key codebase facts (verified)

- Geometry: `crates/pixel-assert/src/geom.rs` — `calibrate()` :252, `CellBox` :296, `Calibration::cell_box(col0, band)` :328 (f64 until one `.round()`; `MARGIN_RATIO 0.35`).
- `analyze_page()` `src/main.rs`:256–310 computes `Calibration` then discards it (`Ok((_cal, outcomes))` :181). Icon slot is always col `3`.
- `verdicts.json` schema: `src/verdict.rs` — `VerdictReport {structural_fail, pass1_support, results: Vec<Verdict{ id, codepoint, overall }>}`; `passing_ids()` :34.
- Sidecar: `crates/matrix-harness` schema v1; `Sidecar.rows: Vec<RowEntry>` with `kind control|candidate`, `id`, `codepoint`, `block`, `page`, `page_row`. Helpers: `rows_for_page(page)`, `entry.page_row()`.
- Catalog (`crates/catalog/src/lib.rs`): `Candidate {id, codepoint, block, fallback}`, `Block::ALL` (8 blocks, manifest order). **No human-readable Unicode names exist anywhere** — `unicode_name` cannot be populated without a new dep, so it is omitted (see schema below).
- CI layout downloaded by `manifest` job: `artifacts/verdicts-<os>/{verdicts.json, artifacts/sidecar.json, pages/shot_page_N.png}`. Pages must be sorted **numerically**.
- Existing tests synthesize full pages (`draw_page`, `sidecar_json`, `pass1_json` in `main.rs:346–453`) with consts `ORIGIN_X/PITCH/CELL_H`.

## File changes (ordered)

### 1. NEW `crates/pixel-assert/src/grid.rs`

Public API:

```rust
pub struct GridInput { pub label: String, pub root: PathBuf } // label ∈ {linux, macos, windows}
pub fn export_grid(inputs: &[GridInput], out_dir: &Path) -> anyhow::Result<()>
```

Algorithm (all-or-nothing: compose in memory, write files only on success):

1. Validate inputs: exactly three, labels distinct and within `{linux, macos, windows}`.
2. Per input, read `<root>/verdicts.json` → `VerdictReport`; bail if `structural_fail.is_some() || !pass1_support` (mirrors manifest-gen fail-closed).
3. Canonical sidecar = linux input's `<root>/artifacts/sidecar.json`. Verify every other platform's sidecar has the identical ordered candidate sequence `(id, codepoint, page, page_row)`; bail on mismatch.
4. Survivors = intersect `passing_ids()` across the three reports; sort by `(Block::ALL.position(block), codepoint)`; block resolved via `icon_catalog::candidates()` id→Candidate lookup (bail on unknown id).
5. Per platform, **strictly sequential page loading** (never hold more than one page buffer in memory — CI runners process 51 pages/platform; retaining them all risks OOM): collect `<root>/pages/shot_page_*.png`, sort by parsed numeric suffix, require count == `sidecar.pages`. Then iterate pages one at a time: `image::open` → capture-gate entropy check (`validate::measure` + `min_entropy`) → `grayscale` → `estimate_background` → `suppress_structural_lines` → `find_text_bands`/`select_grid_bands` → `calibrate` (via the refactored helper from step 2 below) → extract this page's survivor crops into a `HashMap<(label, id), RgbImage>` of small tiles only → **drop** the `DynamicImage`/`GrayImage` before advancing. Any geometry error ⇒ bail.
6. Crop extraction with **hard bounds clamping** (rounding at canvas edges can push `x + w` 1 px past the buffer and panic inside `view(...).to_image()`):
   ```rust
   let x = box.left.min(img.width().saturating_sub(1));
   let y = box.top.min(img.height().saturating_sub(1));
   let w = (box.right - x + 1).min(img.width() - x);
   let h = (box.bottom - y + 1).min(img.height() - y);
   let crop = img.view(x, y, w, h).to_image();
   ```
   (`CellBox.left/right/top/bottom` are already u32 from `cell_box`; clamp against each page's actual dimensions.)
7. Slot math: `slot_w = max(all crop widths) + 2`, `slot_h = max(all crop heights) + 2` (1 px padding each side). Each tile = `RgbImage::from_pixel(slot_w, slot_h, Rgb([0,0,0]))` with crop pasted centered via `image::imageops::overlay`.
8. Compose canvases:
   - `universal-grid.png`: `16 × ceil(tiles/16)` slots (+ blank separator slot-row whenever the block changes between consecutive survivors).
   - `universal-matrix.png`: `3 × n_survivors` slots; platform column order fixed `[macos, windows, linux]`.
9. Write `grid-index.json` (serde Serialize structs, pretty):
   ```json
   {
     "schema_version": 1,
     "columns": 16,
     "cell_width_px": <slot_w>,
     "cell_height_px": <slot_h>,
     "platform_order": ["macos", "windows", "linux"],
     "tiles": [
       { "index": 0, "grid_row": 0, "grid_col": 0,
         "id": "box_2502", "codepoint": 9474, "block": "box_drawing",
         "matrix_col": { "macos": 0, "windows": 1, "linux": 2 } }
     ]
   }
   ```
   (`unicode_name` deliberately omitted — catalog carries no glyph names; adding one would require a name table dependency.)
10. Determinism guarantee: every ordering is total (block rank, then codepoint); PNG encoding of identical pixels is stable → repeated runs are byte-identical (tested).

Unit tests in this file (reusing extracted fixture helpers):

- Happy path with **two fake platforms at different pitches** (e.g. pitch 14 vs 18, cell heights 16 vs 20) → asserts both PNG dimensions match slot math, index parses, tile count == survivors, matrix cols correct.
- Survivor dropped when it fails on one platform only.
- `structural_fail` in any report ⇒ `Err` and **zero files written**.
- Universe mismatch between sidecars ⇒ `Err`.
- Page count mismatch / missing PNG ⇒ `Err`.
- Edge-clamp helper (`crop_box`) exercised with a `CellBox` extending past image bounds → returns a clamped crop, never panics.
- Byte-determinism: two invocations produce identical bytes for all three files.

### 2. EDIT `crates/pixel-assert/src/main.rs`

- Refactor lines 262–269 of `analyze_page` into a shared helper (used by both `analyze_page` and `grid.rs`):
  ```rust
  fn page_geometry(gray: &GrayImage, model: &FgModel, expected_rows: &[&RowEntry])
      -> Result<(Calibration, Vec<Band>), geom::GeometryError>
  ```
  (control-band selection + `select_grid_bands` + `calibrate`). Behavior-preserving; existing tests untouched.
- Extend `Cli`:
  ```rust
  /// Export verified-grid preview PNGs + index instead of asserting.
  #[arg(long, conflicts_with_all = ["pngs", "sidecar", "pass1", "out", "validate_only"])]
  export_grid: Option<PathBuf>,
  /// Artifact roots as label=dir (repeatable; requires --export-grid).
  #[arg(long = "grid-input", requires = "export_grid")]
  grid_inputs: Vec<String>,
  ```
- **Re-relax the four core args**: `pngs`, `sidecar`, `pass1`, `out` currently carry
  `required_unless_present = "validate_only"`; change each to
  `required_unless_present_any = ["validate_only", "export_grid"]` so a bare
  `--export-grid` invocation passes clap validation (the fields stay
  `Option`/`Vec`; `conflicts_with_all` on `export_grid` keeps the modes mutually exclusive).
- Dispatch in `main()` before the normal `run()` path; parse `label=dir` via `split_once('=')`; any error prints `pixel-assert: {err:#}` and exits **2** (existing usage-error convention).

Move `draw_page`/`PageSpec`/`sidecar_json`/`pass1_json`/`tempfile_guard`/`Fixture`/`build_fixture` out of `main.rs` tests so `grid.rs` tests reuse them. **Parameterize** `draw_page`/fixture geometry (origin_x, pitch, cell_h currently consts) so multi-platform fixtures with distinct rasterizations can be synthesized. `main.rs` test module shrinks to imports + existing assertions.

### 4. EDIT `.github/workflows/matrix.yml`

- Workflow root (after `env:`): `permissions: { contents: read }`.
- `manifest` job: add job-level `permissions: { contents: write, pull-requests: write }` (runner jobs stay root-scoped read-only).
- Steps inserted between "Regenerate manifest" and "Drift check" (grids derive from the same verdicts, so they are produced even when the manifest drift check later fails):

  ```yaml
  - name: Generate platform preview grids
    run: |
      mkdir -p assets
      cargo run -q -p pixel-assert -- \
        --export-grid assets \
        --grid-input linux=artifacts/verdicts-linux \
        --grid-input macos=artifacts/verdicts-macos \
        --grid-input windows=artifacts/verdicts-windows
  ```

- After "Upload regenerated manifest":

  ```yaml
  - name: Upload preview grids
    if: always()
    uses: actions/upload-artifact@v4
    with:
      name: universal-icon-grids
      path: assets/
  - name: Open assets update PR
    # Asset PRs only from main pushes/dispatches; never from PR-triggered runs.
    if: always() && github.event_name != 'pull_request' && github.ref == 'refs/heads/main'
    uses: peter-evans/create-pull-request@v7
    with:
      base: main
      branch: chore/update-assets
      add-paths: assets/*
      commit-message: chore(assets): update platform grid previews
      title: chore(assets): update platform grid previews
      body: |
        Automated platform preview grids from CI matrix execution.
        Review the visual diff and merge. Note: if src/generated_manifest.rs
        also drifted, regenerate it locally per the drift-check instructions.
  ```

  (`create-pull-request` is a no-op when `assets/` matches the base branch.)
