# Plan: `--export-grid` visualization mode + CI asset PR automation

Supersedes `.opencode/plans/1787538324705-kind-meadow.md`, amended over two review rounds.

## Architecture (final)

**Separation of concerns:** `pixel-assert --export-grid` is a pure visualization engine. It never reads `verdicts.json` and has zero awareness of pass/fail criteria or hysteresis math. It consumes an **ID list parsed from a `generated_manifest.rs`-format file** (the sole authority on the shipped set, owned by `manifest-gen`) plus per-platform capture artifacts, and maps ids → cell crops → PNGs.

CI dataflow: `manifest-gen` regenerates `/tmp/generated_manifest.rs` → `pixel-assert --export-grid --grid-manifest /tmp/generated_manifest.rs …`. Using the *fresh* output (not the committed copy) keeps PNGs in lockstep with this run's gate result even when the drift check subsequently fails.

## Verified facts driving the design

- `previous_ids(path)` (`crates/manifest-gen/src/main.rs:153`) scrapes `id: "…"` lines; missing file ⇒ empty set. Works identically on fresh or committed manifest files.
- `load_ucd_names(path)` (:93) parses vendored UCD `codepoint;name;…`; absent name ⇒ empty string.
- `manifest-gen` is bin-only; deps anyhow/clap/serde/serde_json/icon-catalog. Adding a lib target exposing the two parsers creates no cycle (`pixel-assert → manifest-gen`).
- Sidecar schema v1 (`crates/matrix-harness`): `Sidecar.rows: Vec<RowEntry>` (`kind control|candidate`, `id`, `codepoint`, `block`, `page`, `page_row`), helpers `rows_for_page(page)`, `entry.page_row()`. pixel-assert has its own `schema.rs` types.
- Geometry: `calibrate()` geom.rs:252, `CellBox` :296, `Calibration::cell_box(col0, band)` :328; icon slot col 3; `analyze_page` main.rs:256–310 discards calibration at :181.
- CI `matrix.yml`: three OS jobs upload `verdicts-<os>` artifacts (`verdicts.json`, `artifacts/sidecar.json`, `pages/shot_page_N.png`); `manifest` job checks out repo, runs `manifest-gen --out /tmp/generated_manifest.rs`, then drift-checks against committed `src/generated_manifest.rs`.

### 2. NEW `crates/pixel-assert/src/grid.rs`

```rust
pub struct GridInput { pub label: String, pub root: PathBuf }   // label ∈ {linux, macos, windows}
pub struct GridOptions { pub manifest: PathBuf, pub ucd: PathBuf }
pub fn export_grid(inputs: &[GridInput], opts: &GridOptions, out_dir: &Path) -> anyhow::Result<()>
```

Algorithm (all-or-nothing: compose in memory, write files only on success):

1. Validate inputs: exactly three, labels distinct within `{linux, macos, windows}`.
2. Target set = `manifest_gen::previous_ids(&opts.manifest)`; bail if empty ("refusing to render empty set — is the manifest file correct?"). Resolve each id → `Candidate` via `icon_catalog::candidates()` (bail on unknown id); sort survivors by `(Block::ALL.position(block), codepoint)` — total deterministic order.
3. Canonical sidecar = linux `<root>/artifacts/sidecar.json`. Every platform's sidecar must carry the identical ordered candidate `(id, codepoint, page, page_row)` sequence; bail on mismatch. Every manifest id must exist in the sidecar universe; bail otherwise (catalog skew).
4. Per platform, **strictly sequential page loading** (never hold >1 page buffer; 51 pages/platform): collect `<root>/pages/shot_page_*.png`, sort by numeric suffix, count must equal `sidecar.pages`. Iterate one page at a time: entropy gate (`validate::measure` + `min_entropy`) → grayscale → `estimate_background` → `suppress_structural_lines` → bands → shared `page_geometry` helper → `calibrate` → extract crops for this page's ids ∩ target set into `HashMap<(label, id), RgbImage>` → drop buffers. Any geometry error ⇒ bail.
5. Crop extraction with hard bounds clamping (edge rounding can push 1 px past the buffer):
   ```rust
   let x = box.left.min(img.width().saturating_sub(1));
   let y = box.top.min(img.height().saturating_sub(1));
   let w = (box.right - x + 1).min(img.width() - x);
   let h = (box.bottom - y + 1).min(img.height() - y);
   let crop = img.view(x, y, w, h).to_image();
   ```
6. Slot math: `slot_w = max(all crop widths) + 2`, `slot_h = max(all crop heights) + 2` (1 px `#000000` padding per side); crops pasted centered via `image::imageops::overlay`.
7. Canvases:
   - `universal-grid.png`: **linux crops only** (pinned canonical source), 16 columns × ceil(tiles/16), blank separator slot-row whenever the Unicode block changes between consecutive survivors.
   - `universal-matrix.png`: row per survivor, columns fixed `[macos | windows | linux]`.
8. `names = manifest_gen::load_ucd_names(&opts.ucd)?`. Write pretty `grid-index.json` (schema_version 2) with **the computed slot dimensions**, not placeholders:
   ```json
   { "schema_version": 2,
     "columns": 16,
     "cell_width_px": <slot_w>,
     "cell_height_px": <slot_h>,
     "platform_order": ["macos", "windows", "linux"],
     "tiles": [ { "index": 0, "grid_row": 0, "grid_col": 0,
       "id": "box_2502", "codepoint": 9474, "block": "box_drawing",
       "unicode_name": "BOX DRAWINGS LIGHT VERTICAL",
       "matrix_col": { "macos": 0, "windows": 1, "linux": 2 } } ] }
   ```
9. Determinism: every ordering total; repeated runs byte-identical (tested).

Unit tests (reuse extracted fixture helpers):

- Happy path: fake platforms at distinct pitches/cell heights → both PNG dims match slot math; index `cell_width_px`/`cell_height_px` equal the real computed values and agree with PNG geometry.
- Manifest filtering: ids absent from the manifest are not rendered; manifest id missing from sidecars ⇒ `Err`; unknown id in manifest ⇒ `Err`.
- **Tile-source pinning**: `universal-grid.png` pixels == linux crop (distinct pitches make linux identifiable).
- Names: fixture UCD file → `unicode_name` populated; unknown codepoint ⇒ empty string.
- Sidecar mismatch across platforms ⇒ `Err`; page-count mismatch / missing PNG ⇒ `Err`.
- Clamp helper fed an out-of-bounds `CellBox` returns clamped crop, never panics.
- Byte-determinism: two invocations produce identical bytes for all three outputs.

### 5. EDIT `.github/workflows/matrix.yml`

- Root: `permissions: { contents: read }`; `manifest` job-level: `permissions: { contents: write, pull-requests: write }`.
- Insert **after** "Regenerate manifest" (so `/tmp/generated_manifest.rs` exists) and before "Drift check"; runs only if regeneration succeeded (not `always()` — a failed gate leaves no trustworthy manifest to visualize):
  ```yaml
  - name: Generate platform preview grids
    run: |
      mkdir -p assets
      cargo run -q -p pixel-assert -- \
        --export-grid assets \
        --grid-manifest /tmp/generated_manifest.rs \
        --grid-input linux=artifacts/verdicts-linux \
        --grid-input macos=artifacts/verdicts-macos \
        --grid-input windows=artifacts/verdicts-windows \
        --grid-ucd crates/manifest-gen/ucd/UnicodeData.txt
  ```
- After "Upload regenerated manifest":
  ```yaml
  - name: Upload preview grids
    if: always()
    uses: actions/upload-artifact@v4
    with: { name: universal-icon-grids, path: assets/ }
  - name: Open assets update PR
    if: github.event_name != 'pull_request' && github.ref == 'refs/heads/main'
    uses: peter-evans/create-pull-request@v7
    with:
      base: main
      branch: chore/update-assets
      add-paths: assets/*
      commit-message: chore(assets): update platform grid previews
      title: chore(assets): update platform grid previews
      body: Automated preview grids from the latest verification run.
  ```
  (No-op when `assets/` matches base.)
