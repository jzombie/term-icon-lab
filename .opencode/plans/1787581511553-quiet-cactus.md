# Plan: Font-specimen chart (`universal-catalog.png`) + full-cell display crops

Supersedes the executed asset-gen plan. Two problems, one root cause each:

## Decisions locked with user

- **Fix display first, purge later**: the 51 circled-digit/die-face glyphs (dingbat U+2776–2793, misc U+2680–2685) stay in the catalog. They passed Pass-1 DSR advance + Pass-2 sentinel non-intrusion on all three runners; the preview chopping is export-side crop math, not render failure. After full-cell previews ship, any codepoint showing *emulator-level* truncation gets rejected empirically by refining `check_bleed` thresholds — no manual blacklists.
- **No blanket border-touch rejection** in Pass 2: legitimate full-width primitives (█ ─ ▐) touch their crop edges by design and are proven clean by sentinel comparison.
- **U+2460–24FF (Enclosed Alphanumerics)** was never cataloged; user-visible look-alikes live in Dingbats/Misc Symbols (see above).

## Problem 1 — Sliced glyphs in previews

`export_grid` reuses `cal.cell_box(3, band)` — the assertion window covering only the **central 70%** of the cell (`MARGIN_RATIO 0.35`, geom.rs). Verification *should* be conservative; *display* must not be. Full-width primitives (█ ▐ ─ ◀) are valid icons but render guillotined.

### Fix

- `crates/pixel-assert/src/geom.rs`: add
  ```rust
  /// Full cell extent for display. Safe without insets: the capture row
  /// sandwiches the glyph between side-bearing ASCII sentinels
  /// (`| A<glyph>B |`), so only the glyph's own ink reaches these bounds.
  pub fn cell_box_full(&self, col0: u16, band: &Band) -> CellBox {
      let c = self.cell_center(col0);
      CellBox {
          left:  (c - self.pitch / 2.0).round() as u32,
          right: (c + self.pitch / 2.0).round() as u32 - 1,
          top: band.top, bottom: band.bottom,
      }
  }
  ```
  No left-edge inset — full-width primitives (`█ ─ ▐`) span the exact boundary, and an inset re-guillotines them.
  Unit tests: full-cell box ⊇ center box; no overlap with neighbours' boxes across fractional pitches (mirror `fractional_pitch_survives_without_drift`).
- `crates/pixel-assert/src/grid.rs`: crop extraction uses `cell_box_full`.
- Verification paths (`analyze_page`, checks) **unchanged** — sentinel-based `check_bleed` remains the contract; no blanket border-touch rejection (would false-purge █ ─ ▐).
- Catalog note: U+2460–24FF / EAW-Wide ranges were never candidates (catalog ranges predate this work); documented in plan only, no code change.

## Problem 2 — Layout is a ribbon, not a specimen chart

Font-repo style: ~480 px wide grid, each cell = glyph render + `U+XXXX` activation label beneath, block separators.

### New output: `universal-catalog.png`

Compose third canvas in `grid.rs` alongside matrix/grid (all three still written):

- **Zoom**: crops scaled ×2 nearest-neighbour (`image::imageops::resize` + `FilterType::Nearest`; integer factor preserves crispness).
- **Labels**: `"U+2502"` under each glyph, drawn by a new `crates/pixel-assert/src/font5x7.rs` — embedded public-domain 5×7 bitmap font, `pub const FONT5X7: &[(char, [u8; 5])]` with exactly **19 entries**: `'U'`, `'+'`, `'0'..='9'`, `'A'..='F'`, `' '` (1+1+10+6+1). Rendered via `put_pixel`, scaled ×2 → 10×14 px chars; color `Rgb([200,200,200])` on black. `draw_text(img, x, y, s, scale, color)` advances **`(5 + 1) * scale`** per char (1 px unscaled trailing gap — no glyph collision); unknown chars render as blank advance, never panic.
- **Cell geometry**: `label_w = 6 chars × 10 = 60 px`; `cell_w = max(crop_w×2, label_w) + 12 pad`; `cell_h = crop_h×2 + 6 + 14 + 10 pad`.
- **Columns**: `cols = ((480 - margin) / cell_w).clamp(3, 8)` → final width `cols*cell_w` lands 400–520 px for any platform metrics.
- Ordering `(Block::ALL rank, codepoint)` unchanged; blank separator slot-row on block change (same placement algorithm as grid canvas).
- Deterministic: pure functions of pixels + total orders (byte-determinism test extended).

`TileMeta` gains `"specimen_row"`, `"specimen_col"`; `GridIndexFile` gains `"specimen_columns"`. `"schema_version": 3`. Existing fields unchanged.
