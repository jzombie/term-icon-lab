## Changes

### 1. `crates/pixel-assert/src/geom.rs` — mirrored left gutter

```rust
/// Gutter between sentinel A's central crop and the icon cell's LEFT
/// boundary — mirror of [`Calibration::gutter_span`].
pub fn left_gutter_span(&self) -> (f64, f64) {
    (
        self.cell_center(2) + self.pitch * 0.35,
        self.cell_center(3) - self.pitch * 0.5,
    )
}
```

### 2. `crates/pixel-assert/src/checks.rs` — orientation-aware dual-gutter scan

The two gutters have **opposite icon anchoring**: right gutter starts at the icon's right boundary (`span.0` = icon); left gutter ENDS at the icon's left boundary (`span.1` = icon). A naive shared helper would grant the AA allowance to the sentinel instead of the icon. Therefore:

```rust
/// How many gutter columns past the first are treated as anti-aliasing.
/// 1 = forgive exactly the first column adjacent to the icon boundary
/// (where fractional-pitch AA lands); 0 would be absolute-zero policy.
/// The sentinel-facing end always keeps a fixed 1 px standoff.
const AA_FORGIVENESS_PX: i64 = 1;

enum GutterSide {
    Left,  // icon sits at span.1 — AA shrinks the scan's RIGHT end
    Right, // icon sits at span.0 — AA pushes the scan's LEFT start
}

fn scan_gutter(
    gray: &GrayImage, model: &FgModel, band: &Band,
    span: (f64, f64), side: GutterSide,
) -> bool {   // true ⇒ intrusion detected
    let (g0, g1) = span;
    let (lo, hi) = match side {
        // First gutter pixel is g0+1; forgive AA_FORGIVENESS_PX beyond it.
        GutterSide::Right => (g0.round() as i64 + 1 + AA_FORGIVENESS_PX, g1.round() as i64 - 1),
        // Last gutter pixel is g1-1; forgiveness extends leftward from it.
        GutterSide::Left  => (g0.round() as i64 + 1, g1.round() as i64 - 1 - AA_FORGIVENESS_PX),
    };
    // any model.is_fg pixel in [lo..=hi] × band rows ⇒ true
}
```

Calibration note: with `AA_FORGIVENESS_PX = 1` the right-side range is byte-for-byte today's behaviour (`round(g0)+2`); the change *adds* the mirrored left-side protection at identical tolerance. Zero-tolerance policy = set the constant to 0.

- `check_bleed` Stage A: `scan_gutter(..., cal.left_gutter_span(), GutterSide::Left)` **or** `scan_gutter(..., cal.gutter_span(), GutterSide::Right)` ⇒ `Intrusion`.
- Empty range (very small pitch) ⇒ no scan; Stage B decides (unchanged).
- `bleed_max` unchanged (gross sentinel corruption); new tests: left-bleed synthetic (ink ≥2 px past the left boundary) ⇒ `Intrusion`; ink exactly inside the 1 px forgiveness column ⇒ `Clean`; sentinel-side pixel within the fixed standoff ⇒ `Clean`; right-side range pinned identical to today's `+2` behaviour (regression).

### 3. `crates/manifest-gen/src/main.rs` — delete exit hysteresis, purge dead plumbing

- Survivors = plain intersection of per-platform passing sets (lines ~228–231 stay); delete `failure_counts` re-admission loop (~232–244).
- `generate_from_inputs` loses its `previous: &HashSet<String>` parameter; all callsites/tests updated.
- **Remove the `--previous` CLI field entirely** — it exists solely to feed hysteresis and would be dead under `-D warnings`.
- `lib.rs` keeps exporting `previous_ids` + `load_ucd_names`: `previous_ids` remains live as the scraper behind pixel-assert's `--grid-manifest`; only manifest-gen's own use of it disappears.
- Rewrite tests: incumbent failing one platform is now DROPPED (invert `hysteresis_keeps_incumbent_through_single_platform_flip` → `single_platform_failure_purges_incumbent`); drop `--previous`-related assertions.
- Known tradeoff (accepted by contract): runner-level rendering noise can flap borderline glyphs between runs. Purity outranks stability.

## Execution flow (includes expected one-time red)

1. Land code + tests; local `fmt/clippy/test --workspace` green.
2. Push branch → CI: capture jobs green (new stricter verdicts written), **manifest drift-check FAILS** — expected: committed `src/generated_manifest.rs` predates the purge.
3. Recover via the printed instructions: `gh run download <run> -n verdicts-{linux,macos,windows}` from that run, then locally:
   `cargo run -p manifest-gen -- --inputs v-linux/v-macos/v-windows --out src/generated_manifest.rs`
   (no `--previous`: strict gate, fresh set), commit, push → green with the purified set.
4. Report set-size delta (how many glyphs the strict gate purged) to the user with examples.
