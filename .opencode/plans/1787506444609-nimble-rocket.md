# Plan: Expand symbol catalog (TODO-expand-symbols.md) — AMENDED per code review

## Goal

Add four standard Unicode symbol blocks to the verification catalog so the CI
AND-gate can empirically discover every 1x1 UI icon that renders reliably on
stock macOS/Windows/Linux terminals. Full ranges, no curation; emoji-rendered
survivors are accepted (spatial invariant CELL_WIDTH==1 is the only contract).

New blocks (656 new candidates, 1165 total, 51 pages/platform, ~2.2x capture
time — still minutes per CI job):

## Review amendments incorporated

- **SEV-1 ACCEPTED (Directive 1):** `src/universal.rs` module re-exports are
  deferred entirely to Push B — re-exporting `arrows`/`geometric_shapes`/
  `misc_symbols`/`dingbats` while the committed `generated_manifest.rs` still
  lacks those modules is an E0432 compile failure that would block the quality
  gate. Push A touches only catalog + manifest-gen + pixel-assert + the
  `src/lib.rs` range test.
- **SEV-2 (tofu) ACCEPTED with a stronger fix than Directive 2:** verified in
  `checks.rs::looks_like_tofu` (bbox ≥55% of cell + interior fill ≤15%) —
  hollow outlines (□ ○ △ ◇ ☆ ⚠ ↺) match the missing-glyph signature and would
  be purged. Directive 2's blanket block exemption would let *real* tofu leak
  into the manifest on those platforms. Instead: add a **rectangularity
  requirement** — tofu additionally requires ink in all four corner regions of
  the ink bbox (a tofu box is rectangular; ○ △ ◇ ☆ ↺ have empty corners).
  □ U+25A1 is pixel-identical to tofu and stays purged (correct: it is
  indistinguishable from a missing glyph). No `visibility.rs` exists — the
  change lands in `checks.rs`.
- **SEV-2 (footer row 25) REJECTED:** the premise is false. `render.rs:14–17`
  reserves physical row 25 (`FOOTER_ROW_1BASED`) for the probe — pages carry
  1 control + **23** candidates (rows 1–24), never 24 candidates; the row is
  documented "never carries candidate ink", unit-tested
  (`footer_probe_targets_reserved_row`), and `pass1::wait_footer` correlates
  on exactly `\x1b[25;1R`. `MIN_ROWS = 30` already guarantees the row exists.
  No collision exists; moving the probe to row 26 would break the documented
  coordinate contract for zero benefit.

## Risks / notes
- Emoji-presentation symbols (⚙⚠✔✂) are mostly eliminated by Pass 1 width or
  Pass 2 bleed; 1-cell survivors accepted by design (user decision).
- □ U+25A1 will be purged as tofu — indistinguishable from a missing-glyph
  box; documented trade-off of the rectangularity rule.
- Sparse glyphs (tiny ♡ etc.) may fail the 2% Blank floor and shrink the set —
  acceptable; tune `eps_for` later only with evidence.
- Run-to-run borderline flips can trip the drift check; remedy is the
  documented regenerate-and-commit loop.
