# Plan: Icon gallery + search (`crates/icons`, Unicode names, metadata manifest)

## Goal

Make the 125 verified icons visible and searchable:
- `manifest-gen` emits **runtime metadata** (id, codepoint, block, official
  Unicode name) alongside each `SafeIcon`, sourced from a vendored
  `UnicodeData.txt` extract — no hand-curated tables, zero lib deps added.
- New workspace crate **`crates/icons`** (clap): `gallery`, `search`, `show`,
  `export --markdown`.
- `term-icon` gains a non-breaking metadata API (`ICON_ENTRIES`, `search()`);
  `SafeIcon` and `UNIVERSAL_ICONS` stay untouched (zero-dep contract intact).

## 1. Vendored Unicode names

- **`scripts/update-ucd.sh`** (new): downloads
  `https://www.unicode.org/Public/UCD/latest/ucd/UnicodeData.txt`, keeps only
  lines whose codepoint falls in the 8 catalog ranges
  (0x21-7E, 0x2190-21FF, 0x2500-257F, 0x2580-259F, 0x25A0-25FF, 0x2600-26FF,
  0x2700-27BF, 0x2801-28FF), writes
  **`crates/manifest-gen/ucd/UnicodeData.txt`** (~1165 lines, ~80 KB, vendored).
  Run it once now; re-run only when catalog ranges change.
- Skip `First>`/`Last>` range-marker lines (our ranges are fully enumerated).
- Parse: field 0 = codepoint, field 1 = official name (ASCII, uppercase).

## 2. `crates/manifest-gen` — metadata codegen

- `main.rs`: new arg `--ucd <path>` (default
  `concat!(env!("CARGO_MANIFEST_DIR"), "/ucd/UnicodeData.txt")` — works locally
  and in CI checkout). Load into a `HashMap<u32, String>` at startup; missing
  codepoint → empty name + one stderr warning (never fails codegen).
- **UCD parsing is bounds-checked** (review Directive 2): extract fields via
  `line.split(';')` + `fields.next()` pattern matching — never index split
  slices. Malformed/short lines are skipped with a counted stderr warning.
- `codegen.rs`: `Entry` gains `unicode_name: String`. Emission adds:
  ```rust
  /// Richer per-icon record (id/codepoint/block/name) for tooling.
  pub struct IconEntry {
      pub icon: SafeIcon,
      pub id: &'static str,
      pub codepoint: u32,
      pub block: &'static str,
      pub unicode_name: &'static str,
  }
  pub static ICON_ENTRIES: &[IconEntry] = &[ ... ];  // same order as UNIVERSAL_ICONS
  ```
  `UNIVERSAL_ICONS`, per-block modules, `lookup`, `by_codepoint` unchanged
  (non-breaking). `block` emitted as `&str` via the existing module-name map
  (`"arrows"`, `"box_drawing"`, …) — term-icon stays zero-dep.

## 3. `src/universal.rs` — public API

- Re-export `IconEntry` and `ICON_ENTRIES` from `generated_manifest`.
- Hand-written helper (documented, stable):
  ```rust
  /// Case-insensitive substring match over unicode name, id, block, and
  /// codepoint as hex (with or without 0x/U+ prefix) or decimal —
  /// e.g. "star", "box_25", "2605", "0x25a0".
  pub fn search(query: &str) -> impl Iterator<Item = &'static IconEntry>
  ```
- **Allocation-free predicate** (review Directive 1): all query normalization
  happens once, before iteration —
  1. `query_upper = query.to_uppercase()` (UCD names are uppercase),
     `query_lower = query.to_lowercase()` (ids/blocks are lowercase);
  2. numeric target parsed once: strip `0x`/`U+` → `u32::from_str_radix(_, 16)`,
     else decimal parse → `Option<u32>`;
  3. the `.filter()` closure only runs non-allocating
     `str::contains(&str)` / integer equality against those precomputed
     values — zero heap allocations per element.

## 4. `crates/icons` — new CLI crate (workspace member)

- `Cargo.toml`: deps `term-icon` (path) + workspace `clap` derive; bin name
  `icons`. Root `Cargo.toml`: add to `workspace.members`.
- Subcommands (single table renderer shared by all: columns
  `GLYPH | ID | CP | BLOCK | UNICODE NAME | FALLBACK`):
  - `icons gallery [--block <name>]` — all entries grouped by block in
    codepoint order.
  - `icons search <query>` — `term_icon::search()` results.
  - `icons show <id-or-codepoint>` — exact hit via `lookup()` (id) or
    codepoint parse (`0x…` hex / decimal) → `by_codepoint()`; prints detail
    view incl. derived Rust const path (`id.to_uppercase()`).
  - `icons export --markdown [<path>]` — deterministic Markdown: one
    `## <block>` section per block, tables `| Glyph | Id | Codepoint | Name |
    Fallback |`; write to stdout or file. Output committed once as
    `GALLERY.md` (no CI enforcement — avoids drift-check churn).
- No other deps; hand-rolled column padding (names ≤ 48 chars).

## 5. Regenerate + commit

- Re-run manifest-gen against the latest verified verdicts

  gains `IconEntry`/`ICON_ENTRIES`; drift check stays consistent
  (generation is deterministic).
- Generate and commit `GALLERY.md`.
